# Dæmi

Þessi mappa geymir lítil dæmi um notkun Beygis. Hvert dæmi er sjálfstætt og er
með nánari keyrslu- eða notkunarleiðbeiningar í skránni sjálfri.

- [beygingartafla/beygingartafla.ts](beygingartafla/beygingartafla.ts) prentar
  einfalda beygingartöflu fyrir uppflettiorð eða beygingarmynd.
- [lemmari/lemmari.ts](lemmari/lemmari.ts) finnur möguleg uppflettiorð fyrir
  orð í stuttum texta.
- [bín-kjarni/smíða.ts](bín-kjarni/smíða.ts) smíðar minni gagnaskrá með færslum
  úr BÍN-kjarna (`birting === "K"`).
- [vefur/index.html](vefur/index.html) sýnir lágmarksdæmi um notkun á
  vefútgáfunni með gagnaskrá sem er sótt og alfarið lesin beint í vafranum.
